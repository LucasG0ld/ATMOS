# Politique de sécurité

ATMOS ne traite ni compte utilisateur ni donnée serveur. Pour signaler une vulnérabilité, ne pas ouvrir d’issue publique contenant des détails exploitables. Utiliser **Report a vulnerability** dans l’onglet Security du dépôt ; le signalement privé de vulnérabilité GitHub est activé et transmis au propriétaire du dépôt.

Le signalement devrait inclure la version ou le commit, les étapes de reproduction, l’impact estimé et, si possible, une mitigation. Un accusé de réception et une fenêtre de traitement seront définis avant la version 0.1.

Les pratiques attendues sont détaillées dans [Sécurité et vie privée](docs/operations/security-and-privacy.md).
